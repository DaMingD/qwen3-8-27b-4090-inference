## 结果表怎么来的

`交付/结果表.md`、`结果表.json` 由下面的命令从原始结果生成，其他材料里的数字用同一份数据渲染：

```bash
python3 工具/build_results.py --night 实测结果/20261101_夜间
```

重新生成需要把原始结果包解压到仓库根目录，并把赛方 `eval/` 放到 `参赛资料/eval/`。环境记录在 [环境](环境/requirements.lock) 目录。
